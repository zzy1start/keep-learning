## 1. 六条反馈的根因与修复

| # | 反馈 | 根因（代码/数据事实） | 修复 |

| 1 | 新词学习界面英文没有音标（destined 显示 `//`） | 词书数据 `ph` 是空占位：destined = `"/  /"`；cet6 共 78/3991 个词是这种占位。卡片直接渲染 `w.ph` | `js/views/vocab.js` 新增 `vocabPh(word)`：占位/空时回退内置词典音标，并统一 `/…/`、把 ASCII `'`/`:` 修为 `ˈ`/`ː`；新词卡/选择题卡/拼写卡/详情页全部走它 |
| 2 | 拼写练习一直是这几个单词；「按时间/乱序」没用 | ① `mirrorToSrs` 每次把整本词书 `srs.last` 刷成 now → 排序全相等 → 稳定按字母序永远前 20 个；② 拼写模式只建 `slots` 不维护 `queue`，按钮改的是上一个模式遗留的 queue | `_arrangeSpell` 改用引擎逐词真实作答时间 `lastGradedAt`（无记录才退回 srs；整组无时间则随机）；拼写模式补 `this.queue = slots.map(wordRef)`；`spellOrder` 真正重排本轮剩余词位并 toast；拼写作答写 `spellAt` |
| 3 | 今日学习不跟进度；测试默认跳过的简单词应计入「已掌握」 | 顶部「已学/已掌握/覆盖率」用 srs 的 reps/interval：定级跳过的 L3 词 attempts=0 既不算已学也不算掌握（截图 34 vs 认识 3259）；「今日复习」恒等于待复习总数，复习多少都不变 | 新增 `_engineCounts()`：把 L3 且从未作答的“测试跳过/自评认识”词计入「已学」「已掌握」，覆盖率同口径；`_todayReviewDone()` 用引擎事件日志统计今天真正复习过的词数与待复习并排显示；「整带跳过 N 个」改为「N 个频带」；引擎卡加“测试跳过 N 词·已计入掌握” |
| 4 | 听力写模式模糊题干时，题号也被糊掉 | CSS `.listen-quiz-question-hidden .qt{filter:blur(6px)}` 把整行（含题号）模糊 | 题干拆 `<span class="qt-no">1.</span>` + `<span class="q-stem">…</span>`；CSS 只模糊 `.q-stem`，题号清晰 |
| 5 | 六级听力提交后没有解析（请复查四级） | 数据事实：`data/content/listening.json` 21 题 explain/evidence **0/21**；CET4 `listening-cet4.json` 20/20 有；设备导入的 2023-12 六级也为空。界面仍渲染空「解析」蓝框 | 空解析至少显示「正确答案：B. 选项原文」；AI 可用且有原文时提交后**一次请求**为整篇补 explain+evidence（evidence 必须逐字出自原文，否则丢弃），写 `Store.d.lsnExplain[passId]` 持久缓存并局部重渲染；未配置/失败静默降级、只提示一次，不阻塞判分；CET4 已有解析行为不变 |
| 6 | 听力无法自动上网抓文本；长对话显示“说话人识别失败” | 补原文弹窗只能粘贴（docs/31 里本就未实现 URL 抓取）；`detectGenders` AI 失败时直接放弃 → 全篇同一音色 | 补原文弹窗新增 URL + 「联网抓取」：仅 http/https、10s 超时、`extractArticleText` 纯函数抽正文、失败分类提示；APK 内经 `native-http.js`/CapacitorHttp 跨域，抓完只填文本框不自动提交 AI。说话人：对话类且无 M/W 标注、AI 失败时按行交替 male/female，独白保持同一音色 |

## 3. 未做/限制

- 真机复验已完成（见 §4）：第 4/5/6 条的视觉、真实 AI 解析、真实网页抓取均按表验证。复验前一度无线 ADB 不可达（设备不在电脑同网段），最终由用户把平板接到电脑热点后连通。
- 第 6 条的“自动”是**由用户提供网页 URL 后自动抓正文**；应用内没有搜索引擎 API，不能凭空搜索 Tapescript。抓取只适合静态 HTML，遇到反爬/登录墙会给出失败原因。
- AI 解析需要配置 API；每篇只请求一次并缓存，清数据/换设备后会重新生成。evidence 与原文不完全一致时会被安全丢弃（只保留解析）。
- 第 3 条的「已掌握」现为“L4 作答过 + 词频落在测试跳过带里的词（按**频带**统计，练过也不会掉数）”，顶部数字会明显变大（真机 34 → 3360），这是用户要求的口径；若希望区分展示可再加“手动掌握/测试跳过”明细。
- 真机测试限制：adb `input text` 在中文输入法下会插入“热”字，拼写输入用 CDP 填值规避；真实用户软键盘输入不受影响。
