## 1. 源图与设计处理

源图：`work/logo-source/new-logo-2026-11-14.png`（1254×1254，RGB，无透明通道）。

源图本身是一张完整的圆角方形 App 图标，卡片边界实测在 `(171,171)–(1077,1077)`。
生成脚本：`work/logo-assets/generate_new_brand_card.py`。

处理策略：

| 用途 | 处理 |
| --- | --- |
| Web/PWA 图标 `icon-180/192/512` | 原图圆角卡片，放在 `#f4f6fb` 背景上，带柔和投影（与旧版 Web 图标同一视觉语言） |
| maskable 512 | 白色底 + 抠出的书本标记，保证在 80% 安全圆内 |
| Android legacy `ic_launcher.png` | 原图圆角卡片，圆角外透明 |
| Android round `ic_launcher_round.png` | 同一卡片做圆形裁切 |
| Android adaptive 前景 | 只保留蓝/青书本标记（饱和度抠图），白色卡片不进入前景层，避免被系统遮罩裁成方块 |
| Android splash | 白底 + 居中圆角卡片 + 轻投影，按 11 个屏幕尺寸重新生成 |
| `logo.png` / `logo-lg.png` | 原图圆角卡片（160 / 512），圆角外透明 |
| favicon.svg | 内嵌 256px 圆角卡片，64 viewBox 内缩 4px |
| `english-app.ico` | 16/24/32/48/64/128/256 多尺寸 |

> 说明：Web 图标与桌面快捷方式沿用旧版“浅色卡片 + 投影”的展示方式；Android adaptive/maskable 用透明书本标记，避免白卡片在圆形/方形遮罩里出现硬边。

## 4. 用户侧生效方式

- **网页版/PWA**：刷新页面；Service Worker 会因 `v34` 清掉旧缓存并重新预缓存新图标。
  若浏览器仍显示旧 favicon，强制刷新（Ctrl+F5）或关闭标签页重开。
- **Windows 桌面快捷方式**：旧的 `.lnk` 里缓存了旧图标；运行一次
  `创建桌面快捷方式.bat`（或 `tools/make-lnk.js`）重新生成即可。
- **Android**：`android/res` 与包内 Web 资源已更新，但**已安装的 APK 不会自动变**；
  需要重新 `cap sync` 并打包/安装。若只更新网页版，不需要动 APK。
