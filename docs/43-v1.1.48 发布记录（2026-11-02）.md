## 5. 1.1.47 → 1.1.48 变更摘要

- **已做标记**（docs/41）：新增 `js/done.js`（只读汇总，零数据迁移）；听力/阅读/写作/翻译共用选择器追加
  `✓已做 xx%`、套卷 `已做 x/y 篇`、页头徽章；提交后原地刷新、重做不重复计数；写作/翻译新记录写入 `taskId`。
- **AI 判断修复**（docs/42）：原生 HTTP 超时 60s → 300s + JS 侧 `Promise.race` 守卫；推理模型输出预算
  8000/12000/16000；`/models` 能力缓存 + 视觉模型自动路由；翻译分数归一化；图片-only 完整性；JSON 修复 +
  `response_format` 降级；超时/连接中断重试。
- **版本/缓存**：versionCode 71 → **72**，versionName 1.1.47 → **1.1.48**，PWA 缓存 v24 → **v25**。

## 6. 已知限制（沿用 docs/41 §5、docs/42 §5）

- 「只看未做」筛选（方案 C）本轮未做：需同时改筛选、计数与空结果回退，建议单独一轮。
- 写作/翻译**旧记录**按标题保守匹配「已做」（不做模糊包含，避免误标）；新记录已带 `taskId`，以后会越来越准。
- 推理模型批改长文仍需 **1–2 分钟**（模型侧耗时）；现在不会再被 60s 掐断，但等待时间仍长。
- 图片识别质量取决于拍照清晰度；识别结果会显示在界面，用户可核对。
- `/models` 拉取失败时不会强行切模型，会回退原模型并在失败信息里说明。
