# 离线音频包生成（gen-audio-pack.cjs）

## 为什么仓库里没有 MP3

内置的 11,187 个单词 + 62 句听力音频是用 **Edge TTS** 生成的（女声 `en-GB-SoniaNeural`、男声 `en-GB-RyanNeural`，见 [docs/31-Android-APK构建记录与验收.md](31-Android-APK构建记录与验收.md#L79)）。
批量再分发微软语音合成产物存在许可风险，因此：

- **仓库不提交 MP3**（`.gitignore` 已排除 `assets/audio/`）；
- **官方 Release 是 lite 包**（`build:web:lite` / `--no-audio`，不含音频）；
- 需要离线音频的人，在**自己机器上生成**，只用于本地构建和自用。

这同时解决了另一个问题：APK 体积从约 361MB 降到不含音频的版本（模型仍按现有策略随包，见文末）。

## 依赖

| 依赖 | 用途 | 安装 |
|---|---|---|
| Python 3 | 运行 edge-tts | https://www.python.org/downloads/（勾选 Add to PATH） |
| edge-tts | 调用 Edge 在线语音合成 | `python -m pip install --upgrade edge-tts` |
| ffmpeg | 转 24kbps 单声道、裁首尾静音 | Windows `winget install Gyan.FFmpeg`；macOS `brew install ffmpeg`；Linux `sudo apt install ffmpeg` |

脚本会先探测依赖，缺什么就打印对应安装命令，不会静默失败。

## 一键脚本（Windows，推荐）

双击项目根目录的 [生成音频包.bat](../生成音频包.bat)（ASCII 启动器；实际界面在 [tools/gen-audio-ui.cmd](../tools/gen-audio-ui.cmd)，**请只双击根目录的 bat**）：

- 自动查找 Node（系统 PATH → WorkBuddy 自带 → DSH 运行时 → Program Files）
- 自动查找 Python（PATH → py → Anaconda/Miniconda 常见路径）
- 检测 edge-tts：缺失时可现场用 pip 安装
- 检测 ffmpeg：缺失时引导 winget，或改用 pip 的 imageio-ffmpeg
- 菜单：检查环境 / 试听 5 条 / 全量生成到 `work\test-audio` / 补全 `assets\audio` / 强制重生成 / 打开目录

> 菜单需要键盘输入序号；生成过程中可 Ctrl+C 中断，重跑会续传。

## 用法

```bash
# 1) 只看统计和依赖状态，不生成
node tools/gen-audio-pack.cjs --dry

# 2) 先生成 5 条试听
node tools/gen-audio-pack.cjs --limit 5

# 3) 全量生成（可随时中断，重跑会跳过已完成的文件）
node tools/gen-audio-pack.cjs

# 4) 全部重新生成
node tools/gen-audio-pack.cjs --force

# 5) 只生成单词 / 只生成句子
node tools/gen-audio-pack.cjs --only words
node tools/gen-audio-pack.cjs --only sentences

# 6) 只校验现有包（不联网）
node tools/gen-audio-pack.cjs --check
```

常用参数：

| 参数 | 说明 |
|---|---|
| `--jobs N` | 并发数，默认 4，可 1–8 |
| `--retry N` | 单条失败重试次数，默认 2 |
| `--python PATH` | 指定 Python（自动探测失败时用） |
| `--ffmpeg PATH` | 指定 ffmpeg |
| `--out DIR` | 输出目录，默认 `assets/audio` |
| `--mock` | 不联网，写 2KB 占位文件（仅测试管线，必须配合 `--out`） |

## 输出

```text
assets/audio/
├── index.json                 # version 3：11,187 单词（仅女声）+ 62 句（男女声）
├── words/f/<sha1(text)[:16]>.mp3
└── sentences/
    ├── f/<sha1(text)[:16]>.mp3
    └── m/<sha1(text)[:16]>.mp3
```

- 文本来源：五本词书 `data/{cet4,cet6,kaoyan,sat,toefl}/*.json` 的 `w` 字段（按小写去重，11,187 个），以及 `data/content/listening.json` + `listening-cet4.json` 的 `passages[*].script[*].en`（62 句）。
- 若目录里已有 `index.json`，脚本优先使用其中文本（保证与已有文件/音色一致）；想从 `data/` 全量重建，先删除 `assets/audio/index.json`（或整个目录）再跑。
- 全部文件生成完成后才写 `index.json`；`--limit` / `--only` 只生成一部分时不会写索引（避免 App 以为音频齐全），完成后跑一次全量即可。
- 失败清单写到 `work/audio-gen-failures.json`，重跑会重试失败项。

## 体积与耗时

- 完整包：约 47MB（24kbps 单声道）。
- 生成耗时取决于网络与并发，通常 **30–120 分钟**（默认并发 4）；脚本每 25 条打印进度和预计剩余时间。
- 生成的 MP3 **不要提交 git、不要上传公开 Release**；只留在本地用于构建/自用。

## 与构建的关系

```bash
# 官方 lite 构建：明确排除音频
node tools/build-android.cjs --no-audio

# 本地带音频构建：先生成，再正常构建
node tools/gen-audio-pack.cjs
node tools/build-android.cjs
```

- `--no-audio`（或 `KEEP_LRN_NO_AUDIO=1`）会跳过 `assets/audio`，report 里显示 `audio: excluded`。
- 没有音频时 App 自动回退到系统 TTS（`AudioPack.load()` 失败后走原 speech 链路），不会崩溃。
- `node tools/check-audio-pack.cjs` 在缺少音频包时打印 SKIP 并以 0 退出，不会卡住 `check-all`。

## 许可与使用边界

- Edge TTS 是微软的消费级服务，没有“可批量再分发”的明确授权。本脚本只是让**用户在本机为自己的学习生成音频**；生成文件仅限个人使用，请遵守 Microsoft 服务条款。
- 本项目不随仓库/官方 Release 分发这些 MP3；如果你把生成的音频再次上传或打包分发，那是你自己的行为，与本项目无关。
- Piper 模型（`assets/models/piper`，约 258MB）目前仍随 APK，这是**另一个待处理事项**（espeak-ng-data 为 GPLv3、各音色许可需逐个核对）；音频与模型是两件事。
