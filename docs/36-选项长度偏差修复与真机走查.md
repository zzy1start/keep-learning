## 1. 修复：正确项不再锚定「更长」

### 1.1 根因（两条出题链路）

| 链路 | 文件 | 旧行为 |
| --- | --- | --- |
| 词汇量测试（40 题）与背单词兜底 | js/dict.js buildChoices | 正确项用 choiceText(target) 拼 **1~2 个词性**的释义（"名词：秒　形容词：第二"）；干扰项用 choiceText(cand, true) 只显示 **1 条**。正确项天然多一截。 |
| 背单词「认识 → 限时四选一」 | js/vocab-quiz.js choiceFor | 正确项 _correctDef 拼 senses[0..1] **两个义项**；干扰项 _firstDef 只 1 条。且 _correctDef 忽略本题 slot.sense，显示的可能不是被考义项。 |

真机旧版基线（v1.1.37 / versionCode 61，第 1 题 attack）：四选项长度 [5,16,5,5]，
正确项 B = "动词：&；攻击　名词：攻击；抨击"（16 字），**唯一最长**。截图 debug/ui-test/C-02-test-q1.png、C-03-test-answered.png。

### 1.2 修复内容（v1.1.38 起）

1. **四项同构**：正确项也只输出「词性 + 单条常见义项」，与干扰项同一格式；
   _correctDef(entry, sense) 改为显示**本题被考义项**（与引擎 levelAttempts 义项轮换一致）。
2. **长度名次随机化**：每题先在 0~3 里均匀随机"要有几个干扰项严格比正确项长"，
   再按名次从候选池取严格更长/更短的干扰项；某侧不足时随机补位。
   这样"正确项=最长"的概率落在随机水平，长度不再携带答案信息。
3. 干扰项仍只取其他词（保持 2026-10-17 规则），并排除与目标词任何义项同文本的选项。
4. **顺带清理词性解析碎片**：choiceParseTagged 解析 "vt.& vi." 会产出 & 碎片，旧版选项出现
   "动词：&；攻击"；现在 choiceAddGloss / commonDefOf 过滤纯 &/标点碎片，quizPosKey 把 & 当分隔符（n&vt → n）。

## 4. 未修复 / 建议后续

1. **导入时长**（阻塞 3 分钟场景）：3 套 11 分钟。建议改为**后台任务 + 通知**，或"一次选 3 个文件、串行批量导入"，
   并给"预计剩余时间/当前批进度"；或对同一场次的 3 套做切批缓存复用（同一份 listening 文本可命中缓存）。
2. OPTIONS_NOT_4（Pa age One/Two 各 5 题）需逐题核对；建议导入清洗加 PDF 页眉/页脚/页码行过滤，
   顺带修 Passage→Pa age 这类抽取残留。
3. 导入篇目标题退化：Passage One/Two、导入阅读材料；听力卡片不显示"第几套"，同一年月多套时难区分。
   建议标题回填首句/主题，并给卡片加"第 N 套（导入）"标签。
4. 「显示答案」后分数显示满分，建议标注"（答案已显示，不计分）"。
5. 设备 TTS 音色 0 时 Tts.getVoices 每 400ms 轮询（logcat 可见），建议退避重试。
6. 3 分钟限时本身：在"AI 切批"现状下不可行；若用户坚持 3 分钟，只能力保 set1 一套（约 3.5 分钟仍超）。
