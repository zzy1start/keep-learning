# 55 · 四六级写作/翻译评分标准修正（2026-11-14）

> 用户反馈：
> 1. 作文明显跑题仍得 19/30（63%）；
> 2. 四六级写作/翻译不是 30 分制，要求按四六级标准修正；
> 3. 修改建议「综合」和「结构」重复，要求整理。

## 1. 结论：四六级写作/翻译各 15 分

四六级总分 710：

- 写作占 15% = **106.5 分**；
- 翻译占 15% = **106.5 分**；
- 阅卷按 15 分制总体印象分档（常见档位 14/11/8/5/2），再换算成报道分。

参考：[教育在线 · 英语四六级写作翻译满分多少？分值明细+评分标准](https://www.eol.cn/kaoshi/ky/cet/202607/t20260716_2756979.shtml)

所以 App 里把四六级作文写成 **30 分满分**是错的；本次统一改为 **15 分**，并在结果里给出 710 分制换算（约 106.5 的等比例值）。

## 2. 修复内容

### 2.1 标准分制

新增 `AI.examMax(task, kind)`：

| 题型 | 满分 |
| --- | --- |
| CET-4/6 写作 | 15 |
| CET-4/6 翻译 | 15 |
| 考研写作 | 20 |
| 考研英语（一）翻译 | 10 |
| 考研英语（二）翻译 | 15 |
| 单句翻译练习 | 20 |

- `js/views/writing.js`：`_maxScore()` 统一按题目来源推导；写作页/翻译页/自定义题不再默认 30。
- `js/views/translation.js`：`_maxScore()` 同样走 `AI.examMax`，旧数据里的 `expectScore=30` 不再覆盖四六级标准。
- `js/ai.js`：`estimateTotalScore()` 的默认先验改为 `examMax`。
- `data/content/writing.json`、`tools/build-content.js`：所有 CET 写作题 `expectScore` 从 30 改为 15。
- 结果卡在满分 15 时显示「710 分制报道分约 X 分（写作/翻译各占 15%）」。

### 2.2 跑题必须低分

旧 prompt 只写「内容完整性 TR 15」，没有“切题硬门槛”；AI 可以在评语里写“完全偏题”，却仍给 19/30。

现在三层：

1. **Prompt 硬门槛**：`AI.writingStandard()` 要求先判 `taskResponse`；跑题 / 未按要求开头 → 总分 ≤ 满分 33%（15 分制 ≤5 分），且 comment 第一句写明“偏题/未按要求开头”。
2. **结构化字段**：写作返回 JSON 增加 `taskResponse:{onTopic, openingMatched, reason}`；`AI.capWritingTaskResponse()` 见到 `false` 直接把总分压到 ≤33%，四维同步缩放。
3. **评语兜底**：即使模型漏填 `taskResponse`，只要 comment 明确出现“完全偏题/跑题/离题/未按题目要求/未使用规定开头”，也会触发同一上限。
4. **代码侧开头句校验**：题目明确写 `begins with the sentence "..."` 时，`capMissingOpening()` 会逐字核对作文开头；不符合直接压到 ≤33%。不依赖模型是否老实。

用用户这题验证：题目要求以 `People are now increasingly aware of the danger of 'appearance anxiety'...` 开头，原文以 `With the development of technology...` 开头 → 19/30 会被压到 **5/15**（再按篇幅校正）。

### 2.3 翻译按四六级标准

`AI.gradeTranslation()` 现在先判断题目来源：

- CET → `translationStandard()`：四六级 15 分制、总体印象分档、四维各占满分 1/4、漏译/空白/抄原文/完全偏离按最低档；
- 考研 → 原考研英语（一）/（二）标准。

单句练习也改走翻译评分，不再误用写作 rubric。

### 2.4 修改建议去重

原来 5 个页签：

`综合 / 结构 / 语言 / 词汇升级 / 句式`

「综合」= `structure + language` 再抄一遍，点「结构」看到的内容与综合重复。

现在 4 个互斥分类：

- 写作：**内容与结构 / 语言表达 / 词汇升级 / 句式语法**
- 翻译：**语义与信息 / 译文表达 / 词汇升级 / 语法规范**

`综合` 页签删除；默认显示第一个分类。AI prompt 的 `structure` 也明确只放“内容/切题/结构”建议，不再与语言建议混在一起。
