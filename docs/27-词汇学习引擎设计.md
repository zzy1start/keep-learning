## 1. 术语表

| 中文 | 英文标识 | 定义 |
|---|---|---|
| 层级 | level | 词（义项）的掌握等级：L0 生词 / L1 眼熟 / L2 模糊 / L3 认识 / L4 巩固 |
| 义项 | sense | 多义词的单个释义单元；引擎以「词 × 义项」为最小状态单位 |
| 轮 | round | 一次 15~20 分钟的学习单元，由 20~30 个词位组成 |
| 词位 | slot | 轮计划中的一个条目，角色为 quiz / review / new |
| 抽检池 | quizPool | 被跳过或自评"认识"的词集合，只被抽检、不被主动教学 |
| 通关 | pass | 单次作答得分：限时内答对 = 1.0 |
| 半通关 | half-pass | 超时（犹豫）后答对 = 0.5 |
| 犹豫 | hesitation | 作答用时超过该层级的答题限时 |
| 熔断 | circuit-break | 同词同轮错 2 次后，本轮只教不考 |
| 难词 | hardWord | 熔断 / 打回事件的标记，下轮优先复现 |
| 错因 | errorType | polysemy（一词多义混淆）/ confusable（形近混淆）/ forgotten（遗忘）/ timeout（超时） |
| 频带 | band | 词表按难度分的组（如初中/高中/四级/六级/雅思托福/GRE） |
| 定级 | placement | 首次使用时的词汇量测试与起点判定 |
| 校准期 | calibration | 定级后的前 2 轮，抽检率提高 |
| 静态先验 | staticPrior | 词对所有人的一般难度（频带、义项数、形近簇） |
| 难度分 | difficulty | 静态先验 + 个人动态失误惩罚，用于调度排序 |

## 2. 设计目标与非目标

### 2.1 目标（按优先级）

1. **防"假性认识"**：任何"看着眼熟但选错意思"的情况不得记为学会（再认 ≠ 回忆）；任何不被主动学习的词必须保留一条复现路径
2. **分层通关**：一轮的"学会"按层级有不同标准，不是全员做对一遍
3. **难度自适应**：难度 = 静态先验 × 个人历史，动态调整复习优先级
4. **焦躁保护**：连续失败时优先保动机（恢复题、熔断、顺延），不硬撑

### 2.2 非目标（v1 不做）

- 发音、拼写题型（v2）
- 服务端同步、多端、账号体系
- 词库数据生成（依赖外部数据，格式要求见 §4.1）
- 自动调参（v1 只上报指标，由人工调 CONFIG）

## 5. 核心算法

### 5.1 冷启动定级（placement）

输入：各频带抽样测试结果 `[{ band, sampled, correct }]`。题型必须是**限时四选一**；若复用现有词汇量测试模块，必须确认它按频带输出正确率（见 §10-Q1）。

```
1. 逐带计算 accuracy = correct / sampled
2. skipBands = 所有 accuracy >= PLACEMENT.SKIP_RATE 的带
   startBand = 第一个 accuracy <  PLACEMENT.START_RATE 的带索引
3. 逐词定级：
   - 属于 skipBands 的词                            -> level = 3, inQuizPool = true
   - 属于边界带（START_RATE <= accuracy < SKIP_RATE） -> level = 1
   - 属于 startBand 及其后（更难）的带                -> level = 0
   - 任何带中抽样答对的词                            -> level = 3, inQuizPool = true（覆盖上面各条）
4. vocabEstimate = round( sum( correct_i * bandSize_i / sampled_i ) )
5. calibrationRoundsLeft = PLACEMENT.CALIBRATION_ROUNDS
```

设计说明：边界带的词直接进复习块考（会的一秒过、不会的走反馈重考）——**测试管粗，轮次管细**。

### 5.2 组轮（composeRound）

```
1. 若 dailyNewDate != 今天 -> dailyNewCount = 0
2. 抽检位（quiz）：
   a. 候选 = 全部 L3 + 全部 L4
   b. 优先取 nextDueAt <= 今天的 L4（越 overdue 越优先）
   c. 其余名额：先取 inQuizPool && !quizAudited 的词（最近跳过、未审计，风险最高）
   d. 再其余：从剩余 L3 中随机
   e. 数量 = clamp(round(rate x 候选总数), min, max)；校准期用 QUIZ_CALIBRATION，否则用 QUIZ
3. 复习位（review）：L1/L2 中取 12~15 个，
   排序分 = difficulty x (hardWord ? HARD_WORD_PRIORITY_BOOST : 1)，高的优先
4. 新词位（new）：L0 中从未出场（attempts == 0 且 levelAttempts == 0）的取
   min(8~10, 今日目标剩余额度) 个，顺序默认随机。**【2026-10-23 调整：每日新词目标生效，达标可继续加学】**
   UI 组轮时传入 `dailyNewTarget`（Store.settings.dailyNew）；今日已安排数记在 `user.dailyNewCount`。
   - 未达目标：本轮新词位 = min(每轮上限 10, 本词书剩余 L0, 今日剩余额度)
     （目标 30 = 10+10+10；今天只剩 5 个额度时这一轮只出 5 个）；
   - 已达标/超额：**仍可继续加学新词**（每轮 ≤10），置 `round.newOverGoal = true`，
     不强制改复习——复习有独立入口与到期词（2026-10-23 用户追加要求）；
   - 只有词书没有 L0 新词时，才自动改智能复习轮并置 `fallbackReason='no-new'` /
     `round.fallbackFromNew = true`，UI 提示"新词已学完"。
   换轮时对账：上一轮没学完就被新轮取代，未学的新词位会从 dailyNewCount 扣回，不重复占额度。
5. 各角色数量不足时取实际可用数；quiz + review + new < ROUND_MIN_WORDS -> 组成短轮
6. 执行顺序固定为 quiz -> review -> new（认知负荷由轻到重）
```

### 5.3 单题判定（grade）

```
输入：作答事件（wordId, senseId, role, responseMs, selectedOptionId）
1. timeLimitMs = ANSWER_TIME_LIMIT_MS[level]（L4 取 L3 的限时）
   timedOut = responseMs >= timeLimitMs（前端到时限自动交卷，见 §7.1）
2. correct = (selectedOptionId == answerId)
3. score = correct ? (timedOut ? 0.5 : 1.0) : 0
4. errorType 推断（仅错误时）：
   - selectedOption 属于该词其他义项的释义   -> polysemy
   - selectedOption 属于 confusableWith 集群  -> confusable
   - timedOut                                -> timeout
   - 其他                                     -> forgotten
5. 更新计数：attempts++, levelAttempts++, streak += score；
   犹豫时 hesitationMsSum += responseMs（仅犹豫计入）
6. 执行 §5.4 迁移，返回 UI 指令（§7.2）
```

出题侧规则（干扰项生成）：

- 4 个选项 = 1 正确 + 3 干扰
- ~~该词有多个义项时，干扰项**必须包含该词其他义项的释义**（多义辨析是设计意图，不是意外）~~
  → **【2026-10-17 修复】禁止用该词自身其他义项当干扰项**：题干只有单词本身（不说明考哪个义项），
  若选项里同时出现"名词 墓地"和"形容词 严重的"，两个都是正确释义，选哪个都可能被判错。
  多义辨析改由**义项轮换**体现（同词不同轮次考不同义项）；干扰项一律取其他词，
  保证每题**有且只有一个**选项属于目标词（见 §12）
- 其余干扰项优先取 `confusableWith` 集群内词的释义，其次同频带随机词的释义；
  **干扰项文本不得与该词任何义项相同**（别的词释义可能与本词另一义项一模一样，
  如 voluntary 的"自愿的；志愿的" = volunteer 的形容词义，放进选项会再次造成"两个都对"）
- 正确义项按 `levelAttempts` 轮换（已在学的词换着义项考，避免记住题目）

### 5.4 状态迁移（transition）

先按 §5.3 累计得分，再按此表迁移：

| 当前层 | 本次结果 | 迁移 |
|---|---|---|
| L0 | score ≥ 1.0 | → L1（streak / levelAttempts 清零） |
| L0 | 本轮第 2 次仍错 | **熔断**：保持 L0，hardWord = true，本轮不再出现，下轮优先 |
| L1 | score ≥ 1.0 | → L2 |
| L1 | 本轮第 2 次仍错 | **熔断**：保持 L1，hardWord = true，下轮优先 |
| L2 | streak ≥ 1.5 且 levelAttempts ≥ 2 | → L3（成为抽检候选） |
| L2 | 本轮第 2 次仍错 | **打回 L1**：streak / levelAttempts 清零，hardWord = true |
| L2 | 第 1 次错 | 留 L2，反馈讲解，按 MIN_GAP_SAME_WORD 安排同轮重考 |
| L3 | 抽检限时内答对 | → L4，nextDueAt = 今天 + INTERVAL_LADDER_DAYS[0] |
| L3 | 抽检答错或犹豫 | 留 L3（犹豫不得升 L4） |
| L4 | 复现限时内答对 | 留 L4，nextDueAt = 今天 + 下一档（7 → 15 → 30，满 30 保持） |
| L4 | 复现答错 | → L2，streak / levelAttempts 清零，nextDueAt = 今天（立即进复习队列） |

错误标记：polysemy → polysemyRisk = true；confusable → confusableRisk = true。两种标记在升级 / 打回时都不清除，用于后续出题侧重。

### 5.5 间隔队列（scheduling）

- L4 是唯一使用 nextDueAt 的层级；L3 靠每轮抽检（§5.2 步 2）复现
- 到点未抽到不惩罚、不累积，只影响优先级（overdue 越久优先级越高）
- 任何 L3 / L4 作答错误 → DUE_MISTAKE_RESET：打回 L2 且立即可复习

### 5.6 焦躁保护（anxiety guard）

```
1. 每错一题 consecutiveWrong++，每对一题清零
2. consecutiveWrong >= CONSECUTIVE_WRONG_LIMIT ->
   下一题插入「恢复题」：从 L4 池随机取 1 个（必然答对，重建信心）；
   L4 池为空则退化为「直接展示当前错题答案 + 例句」（产品二选一，见 §10-Q3）；
   插入后 consecutiveWrong 清零，随后恢复原计划
3. 每轮动态监测：errors / attempts > ROUND_ERROR_RATE_STOP 且新词位尚有未完成 ->
   截断：剩余新词位顺延下一轮（这些词状态零变化，不惩罚），本轮提前收尾
```

### 5.7 难度分与调度（difficulty）

```
bandNorm    = band / (BANDS - 1)                 // 0~1
senseNorm   = min(senses.length - 1, 3) / 3
confNorm    = min(confusableWith.length, 3) / 3
staticPrior = 0.6*bandNorm + 0.2*senseNorm + 0.2*confNorm          // ⚠️ 权重可调

errorRate   = errors / max(attempts, 1)
hesitation  = hesitationMsSum / max(hesitantCount, 1) / ANSWER_TIME_LIMIT_MS[level]  // 无犹豫记 0
stuckNorm   = min(stuckRounds, 5) / 5
difficulty  = staticPrior + errorRate + hesitation + stuckNorm     // ⚠️ 三项权重均 1.0，可调
```

用途仅两处，**不做显式四象限分支**：

1. 复习位排序分（§5.2 步 3），hardWord 再乘 HARD_WORD_PRIORITY_BOOST
2. 抽检候选同优先级时，difficulty 高的先被审计

四象限（快速通道 / 正常升级 / 优先复活 / 难词通道）是上述权重的产品解释：常见词总出错 → errorRate 升高 → 自动获得复习优先（优先复活）；生僻词总出错 → staticPrior 与 stuckNorm 双高 → 排序靠前（难词通道）。

### 5.8 轮末报告（report）

```js
{
  roundId, startedAt, durationMs,
  quizzed: { total, passed },
  upgraded: [{ wordId, senseId, from, to }],  // 本轮升级的词
  hardWords: [{ wordId, senseId, action: "break"|"demote" }], // 本轮熔断/打回的词
  roundErrorRate,
  truncated,
  nextRoundFocus: [wordId],   // hardWords + overdue L4，按难度分排序
}
```

文案必须是正向框架（"本轮征服 X 词、烧熟 Y 词"），❌ 禁止"错了 N 个"式呈现。

## 6. 边界情况清单

| # | 情况 | 规定行为 |
|---|---|---|
| 1 | 一词多义只知其一 | 义项独立状态；定级 / 自评只跳过已测义项，未测义项按所属带规则定级（边界带 → L1），❌ 不得直接 L3 |
| 2 | 用户自评"我认识" | 只能置 level = 3 + inQuizPool = true 进抽检；抽检错按 §5.4 打回 L2 |
| 3 | 一轮中途退出 | 已评分事件已落盘，streak 按事件累计；未开始的词位状态零变化，不惩罚不清零 |
| 4 | 同词复现密度 | 每轮每词最多 MAX_ATTEMPTS_PER_WORD_PER_ROUND 次，两次之间至少隔 MIN_GAP_SAME_WORD 道题 |
| 5 | 词池不足 | 各角色取实际可用数；总数 < ROUND_MIN_WORDS → 短轮；仍不足则本轮只有抽检 + 复习 |
| 6 | 超时未作答 | 前端自动交卷，score = 0，errorType = timeout，计入连续错误与同词错误计数 |
| 7 | 单日新词目标 | **日目标 + 可加学**（2026-10-23 调整）：今天先按该数量出新词（每轮 ≤ 10；只剩 5 个额度就只出 5 个）；达到/超过目标后仍可继续加学新词，不强制改复习；中途退出未学的新词位回滚额度 |
| 8 | 校准期审计 | 引擎只上报"各频带抽检错误率"指标；是否上调跳过阈值 / 重新入队由产品决定（v1 不自动调） |
| 9 | L4 池为空 | 恢复题退化为直接展示答案（§10-Q3） |
| 10 | 定级测试中途退出 | 按已完成带估算，vocabLowConfidence = true，校准轮数 +1 |
| 11 | 某带词数 < PER_BAND | 抽样数 = min(PER_BAND, 该带词数) |
| 12 | 旧 srs.js 数据迁移 | stage 0~4 近似映射 L0~L4，inQuizPool = false；⚠️ 建议迁移后对原 stage ≥ 2 的词做一轮 25% 抽检验证 |

## 8. 验收测试（Golden Test）

实现完成后必须逐条跑过，输出与期望不一致即不通过。

### 场景 A · 定级

输入：6 带各抽 12 词，答对 [12, 11, 10, 5, 2, 1]；bandSize = [1000, 1500, 1500, 2000, 2000, 3000]（⚠️ 示例数据）。

期望：

- accuracy = [1.000, 0.917, 0.833, 0.417, 0.167, 0.083]
- skipBands = [0, 1, 2]；bandPlacement = 3；vocabEstimate = 5042（1000 + 1375 + 1250 + 833 + 333 + 250 ≈ 5041.7）
- 第 0~2 带全部词 level = 3 且 inQuizPool = true；第 3~5 带 level = 0；抽样答对的 31 个词一律 level = 3 且 inQuizPool = true
- 本例无边界带（正确率没有落在 0.50~0.80 的带）

### 场景 B · 完整一轮（8 题）

初始：mitigate L3；complement L1（errorTypes: {confusable:1, forgotten:1}）；scale L2（streak = 0）；ubiquitous L0；resilient L0。
轮计划：quiz = [mitigate]；review = [complement, scale]；new = [ubiquitous, resilient]（候选池只有 1 个 L3/L4 词，抽检位实际 1 个，见 §6-#5）。
限时：L0 15s / L1 12s / L2 10s / L3 5s。MIN_GAP_SAME_WORD = 3。

| # | 词 | 角色 | 作答 | 得分 | 期望状态变化 |
|---|---|---|---|---|---|
| 1 | mitigate | quiz | 4s 答对 | 1.0 | L3→L4，nextDueAt = +7 天 |
| 2 | complement | review | 选 compliment 的释义 | 0 | errorType = confusable，confusableRisk = true；安排 3 题后重考 |
| 3 | scale | review | 12s 答对 | 0.5 | streak = 0.5，hesitationMsSum = 12000 |
| 4 | ubiquitous | new | 教学卡后 8s 答对 | 1.0 | L0→L1 |
| 5 | resilient | new | 教学卡后 15s 超时未答 | 0 | errorType = timeout；安排重考 |
| 6 | complement | retry | 答对（间隔 3 题 ✓） | 1.0 | streak = 1.0 ≥ 1.0 → L1→L2 |
| 7 | scale | retry | 3s 答对（换义项例句） | 1.0 | streak = 1.5 且 levelAttempts = 2 → L2→L3 |
| 8 | resilient | retry | 答错（同轮第 2 次错） | 0 | 熔断：保持 L0，hardWord = true，下轮优先 |

轮末期望：upgraded = [mitigate, complement, scale, ubiquitous]；hardWords = [resilient]；quizzed = {total: 1, passed: 1}；consecutiveWrong 峰值 = 1（未触发干预）；roundErrorRate = 3/8 = 0.375 < 0.40（未截断）。

注意第 6、7 题的重考插入点由 MIN_GAP_SAME_WORD = 3 决定，实现必须按"满足 gap 的最早位置"插入，而不是固定队尾。

### 场景 C · 焦躁保护

- 连续两题答错 → 第 3 题必须是恢复题（L4 随机一词），且 consecutiveWrong 清零后恢复原计划
- 构造：5 题中错 3 题（rate = 0.6 > 0.40）且新词位还剩 4 个未完成 → 引擎必须截断：剩余新词顺延，report.truncated = true

### 场景 D · 间隔复现

- mitigate 在 L4，nextDueAt = D+7；D+7 的轮中抽检位必须优先抽到它（overdue 优先）
- 答错 → level = 2、streak = 0、nextDueAt = 当天（立即可进复习队列）
- 限时内答对 → nextDueAt = 当天 + 15（第二档）

## 12. 变更记录

### 2026-10-23 · 每日新词目标真正生效 + "熟悉/跳过/详情"不再循环同一个词

**背景（用户真机反馈）**：
1. 新词卡点「熟悉，查看词义和搭配」后，同一个词在本轮里无限重复——"一直循环背这个单词"。
2. 「学习设置 → 每日新词目标」填了 30，但学习时每轮仍只出 10 个新词，设定看起来完全没用。

**排查与根因**：
1. 「熟悉 / 跳过 / 只看词条详情」只改引擎状态、**不消费当前轮的执行队列**；
   `ViewVocab._advance()` 又用 `round.slots` 整体重建队列 → 刚看过的词位仍在队首，
   `qi` 指向它，于是同一个词反复出现（真机与 tools 复现均稳定）。
2. 组轮 `_selectSlots` 只看 `NEW_PER_ROUND.max`，完全不读 `settings.dailyNew`；
   `dailyNewCount` 只累加不设限，所以目标只是首页文案。另一个口径错误：
   词书页"今日新词"取 `stats.daily.words`，那里把复习/抽检/拼写答对也算进去，
   日目标会被提前判定完成。

**修复**：
1. 引擎新增 `consumeSlot(wordId, senseId, slotObj)`：按**对象身份**从当前轮队列移除词位
   （不误删同词的 retry 重考位）；`ViewVocab._advance()` 在推进前统一消费当前词位。
   熟悉 / 跳过 / 详情→下一个 三条路径都不会再回到同一个词。
2. `startRound({dailyNewTarget})` 传入每日目标：未达标时每轮新词数 = min(每轮上限 10, 本词书剩余, 今日剩余额度)；
   **达到目标后仍可继续加学新词**（每轮 ≤10，`round.newOverGoal=true`），不再自动回退复习——复习走独立入口；
   只有"词书没有 L0 新词"时才回退（`fallbackReason='no-new'`）。
   换轮时把上一轮未学的新词位从 `dailyNewCount` 扣回，避免中途退出重复占额度。
3. 词书页「今日新词」改为引擎口径 `X / 目标`；达标后按钮变「继续学习新单词 → 再加 N 词」；
   学习页 HUD 增加「今日新词 X/N」实时进度；设置弹窗补充目标说明（每轮最多 10 个、分几轮完成、达标可加学）。
4. **首页口径统一**：「今日新学单词」改为引擎新词数（扣掉本轮还没轮到的新词位；引擎不可用时回落旧统计），
   并在卡片下加一句说明"只算新词，不含复习/抽检/拼写答对"——不再出现"今日 39 词 vs 目标 30"的矛盾。
5. 保留兜底：未传 `dailyNewTarget` 的调用（自检、外部脚本）仍按旧的每轮 8~10 软目标运行。

**测试**：

  "今日新词 X/目标 + 达标继续学新词""中途退出不虚高"用例。
- `tools/check-vocab-engine.cjs` 24 项（23 过 / 1 项既有失败）：新增日配额（30→10+10+10→继续加学）、
  只剩 5 个额度只出 5 个、换轮对账、`consumeSlot` 不误删重考位；

### 2026-10-25 · 出题选项「答案总是最长的那条」修复（用户反馈）
**问题**：词汇量测试与背单词的四选一，正确项几乎总是最长的一项，可以只看长度猜答案；
背单词里甚至出现"动词：&；攻击"这种带 & 碎片的选项文本。

**根因（两条出题链路）**：
- `js/dict.js` `buildChoices`（词汇量测试 + 背单词兜底）：正确项 `choiceText(target)`
  拼 **1~2 个词性**的释义（"名词：秒　形容词：第二"），干扰项 `choiceText(cand, true)`
  只显示 **1 条**；正确项长度系统性多一截。
- `js/vocab-quiz.js` `choiceFor`（背单词主链路）：正确项 `_correctDef` 拼 `senses[0..1]`
  两个义项，干扰项 `_firstDef` 只 1 条；且 `_correctDef` 忽略了本题的 `slot.sense`，
  显示的可能不是被考的义项（与"义项轮换"不一致）。

**修复**：
1. 四项同构：正确项也只输出「词性 + 单条常见义项」，与干扰项完全同一格式。
2. 每题**随机指定正确项的长度名次**（0~3 个干扰项严格更长），再从候选池取严格更长/更短
   的干扰项；某一侧凑不够时从池里随机补位。这样"正确项严格最长"的比例回落到随机水平
   （真实词库实测约 0.25，见 docs/36），长度不再携带答案信息。
3. 干扰项仍只取其他词（保持 §5.3 / 2026-10-17 规则），并排除与目标词任何义项同文本的选项。
4. `_correctDef(entry, sense)` 改为显示**本题被考义项**，与引擎 `levelAttempts` 义项轮换一致。
5. 顺带清理词性解析碎片：`choiceParseTagged` 解析 "vt.& vi." 会产生 `&` 碎片（旧版选项
   显示"动词：&；攻击"）；`choiceAddGloss` / `commonDefOf` 现在过滤纯 `&`/标点碎片
   并在词性键里把 `&` 当分隔符（`n&vt` → `n`）。

**回归**：新增 `tools/check-choice-length.cjs`（真实词库 5 本 × 两条链路，共 22,000+ 题），
10 项全部通过；`check-vocab-engine`（24 项）、`check-vocab-options`、`check-vocab-view`
