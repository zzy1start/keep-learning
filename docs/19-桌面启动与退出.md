# 第十九轮：桌面一键启动与退出

## 桌面快捷方式

桌面上的 `Keep Learning.lnk` 指向当前 Node.js 的 `node.exe`，工作目录为项目根目录，参数为：

```text
"<项目根目录>\serve.js" 8777 --open
```

双击后启动本地服务器；服务器成功监听 `127.0.0.1:8777` 后，才打开默认浏览器中的学习页面。`serve.js` 从参数中识别数字端口，因此 `--open` 不会被误当作端口。

`tools/make-lnk.js` 调用 Windows 自带的 `WScript.Shell` Shell Link 接口生成 `.lnk`，不需要 npm 依赖。`.lnk` 是 Shell Link 二进制格式，不是 OLE/CFB 容器。图标使用 `assets/english-app.ico`（由项目 logo 生成，含 16–256px 多尺寸）；脚本先写临时文件，再由 Windows 接口读回并核对目标、参数、工作目录和图标位置。Node 另外检查 ShellLinkHeader、CLSID、IDList、LinkInfo 和关键参数，全部通过后才替换桌面图标。

重新创建桌面图标：双击 `创建桌面快捷方式.bat`，或在项目目录运行：

```text
node tools/install-shortcuts.js
```

如果手写 `.lnk` 失败，安装器会退回桌面 `Keep Learning 启动.bat`。项目搬到新目录后需要重新运行安装器，因为快捷方式保存了当前绝对路径。

## 从学习界面退出

首页底部的「退出学习并关闭服务器」按钮按以下顺序工作：

1. 二次确认。
2. 调用 `Store.flush()` 立即保存浏览器 `localStorage` 中的进度。`Store.save()` 有 400ms 防抖，不能代替退出前的立即保存。
3. 向本地服务器发送带 `X-Exit-Token` 的 `POST /__shutdown` 请求。
4. 服务器返回响应后退出 Node 进程。

点击按钮后，服务器会关闭，页面显示「已关闭」状态；浏览器窗口仍可手动关闭。也可以直接关闭启动快捷方式打开的命令行窗口来结束 Node 进程。

退出接口仅接受 POST、要求自定义请求头，并检查请求来自回环地址。静态资源继续使用 `Cache-Control: no-cache`。

## 数据位置

学习进度保存在浏览器 `localStorage`，不在项目目录里。更换浏览器或设备时，需要从应用中单独导出进度。

相关规范：[Microsoft Shell Link (.LNK) Binary File Format](https://learn.microsoft.com/en-us/openspecs/windows_protocols/ms-shllink/16cb4ca1-9339-4d0c-a68d-bf1d6cc0f943)（访问日期：2026-10-06）。
