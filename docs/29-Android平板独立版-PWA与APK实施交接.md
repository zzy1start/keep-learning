> 2026-10-18 用户明确改为“直接下载安装 APK，AI/音色可联网调用”。现行交接方案见 [30-Android平板APK独立版-实施交接.md](30-Android平板APK独立版-实施交接.md)。本文件仅保留此前 PWA 路线记录，不再作为实施指令。

> 状态：实施交接方案；**尚未完成 Cloudflare Pages 部署、安卓真机验收或 APK 打包**。本文件以 2026-10-18 的工作区源码为依据。用户报告的“约 44 MB、PWA 静态包已做”等属于待真机和发布包核实的状态，不应写成已验收结果。

## 1. 产品边界与技术路线

- 主设备是 **8.8 英寸 Android 平板**。电脑仅通过用户主动导出、导入文件交换进度；不需要电脑开机、热点、本机 Node 服务、账号或自动同步。
- 首选交付 **HTTPS 托管的可安装 PWA**：桌面图标、独立窗口、首次联网取得完整离线资源后离线学习。Cloudflare Pages 只分发**公开的程序和内置资源**，不保存用户学习记录、导入卷子或 AI Key。
- 第二步可把**同一个已验收的 PWA** 用 Bubblewrap 包成 **TWA APK**。TWA 仍由设备上的兼容浏览器运行同一网站；它不是把全部网页资源和数据库封进 APK。首次启动以及清除浏览器站点数据后仍需联网重新取得资源。若用户以后要求“安装 APK 后首次断网也能启动”、绕过 AI 服务的浏览器 CORS 限制，或不能依赖兼容浏览器，再评估 Capacitor 本地资源版；这属于另一轮改造。
- 不做手机专项适配。维持现有桌面版、深色模式和所有模块：单词、听力、阅读、写作、翻译、生词本、统计、树园、设置。
- AI 评分/识别和可选在线音色使用用户配置的外部服务时必须联网，输入会发给相应提供方；“不接云”在此指**不建项目自己的云端用户数据库、不同步用户数据**。离线 TTS 与离线学习不依赖这些服务。

## 2. 当前源码基线与必须先补的缺口

| 事项 | 现状与证据 | 实施要求 |
| --- | --- | --- |
| 平板外壳 | `css/shell.css` 已设 76px Rail，`css/pages-mobile.css` 已设 600–1099px 平板断点、竖屏单词页单列；`manifest.webmanifest` 为 `standalone` | 保留这套布局；以目标平板的 CSS 视口尺寸实测，不能仅按物理 8.8 英寸推断断点 |
| PWA 缓存 | `sw.js` 预缓存外壳；`data/*` 在访问后才缓存，`Promise.allSettled` 允许缺文件仍安装成功 | 增加可核验的“离线资源准备完成”流程，完整下载必需词书、题库、PDF.js 及其字体/CMap、图片；逐项校验失败并支持重试；更新时保留旧完整缓存，直到新版本准备成功 |
| 用户数据 | `js/store.js` 的 `Store.flush()` 写入 `localStorage`；静态站点下 `js/importer.js` 的题库回退写到 `Store.d.contentBackup` | 大体积导入题库迁到 IndexedDB，学习进度也要有可靠迁移与失败提示；不得靠 `localStorage` 承载整套 PDF 导入结果。请求持久存储并保留手动备份，仍须说明用户清站点数据会丢失本机数据 |
| 跨设备备份 | `Store.progressBackup()` 只带当前 `contentBackup`；`Store.importProgress()` 对题库做追加合并；`importedPapers` 未列入 `PROGRESS_FIELDS` | 改成**覆盖式便携快照**，含导入题库正文、导入登记、去重信息和全部学习记录；保留接收设备 `settings`、AI Key。对旧版备份先预览和迁移，不能静默丢内容 |
| 电脑导入题库 | 本机 `serve.js` 可将个人题目写到 `data/content/*.json`；这部分可能不在 `contentBackup` | 电脑导出时必须从已加载题库/磁盘中收集全部 `mine:true` 项，而不是只导出 `Store.d`；不能把个人题目混进公开发布包 |
| 语音 | `js/speech.js` 使用 Web Speech；设置页有试听、音色选择、Android 语音安装指引；可选真人词典音频依赖 `serve.js` 的 `/__dict-audio` | 保留起音时机、播放/停止/重播和男女音色逻辑。平板本地 TTS 必须真机离线发声；在线音色仅在设备实际提供且联网时显示/可选。静态 PWA 不能调用电脑的词典音频代理，需清楚降级到系统 TTS，不能显示“已启用真人录音”却静音 |
| AI、文件与 PDF | `js/ai.js` 直接调用用户设置的 AI API；`js/importer.js` 使用本地 PDF.js；拍照/导出使用网页文件 API | 在目标平板验证 API CORS、文件选择、扫描 PDF 的明确提示、拍照和 PDF/备份下载。不得假设桌面浏览器成功就等于 Android PWA 成功 |
| 发布目录 | README 提到的兄弟静态目录在本次本机检查中不存在；当前 Git 工作区有大量未提交修改 | 从**当前工作区快照**做可复现的静态发布构建；不要 `reset`、`clean` 或用旧 `HEAD` 覆盖用户更改 |

**发布隐私门槛：**当前 `data/content/listening.json`、`reading.json`、`writing.json` 含有 `mine:true` 的个人导入条目。不能把整个仓库或原样 `data/content` 上传 Pages。构建应只包含代码、必要依赖与确认可公开的内置内容，个人题目通过便携备份进入平板。构建完成后扫描发布目录，若发现 `mine:true`、AI Key、备份文件、原始 PDF、`.git`、工具日志，则中止发布。

## 3. 推荐实现结构

1. 新增**确定性的静态构建脚本**，例如 `tools/build-pwa.cjs`（拟新增）：从当前工作区白名单复制 `index.html`、所需 `css/js/assets/data/vendor` 和 `manifest.webmanifest` 到 `dist-pwa/`；剔除个人导入项及开发文件。逐个检查 HTML、JS 动态 URL 和 PDF.js worker/CMap/字体路径。不要直接发布仓库根目录。
2. `sw.js` 维护版本化、可校验的“核心外壳”和“离线内容包”。首次联网自动准备或在设置页显示进度与重试；只有必需文件均成功、尺寸/哈希检查通过，才显示“已可离线”。更新失败保持旧包可用。网络断开时对本机数据返回缓存，对 AI 返回明确的联网提示。
3. 把“公开只读内置题库”和“本机可写个人题库”分层：`data/*` 只读；个人卷子、导入索引和大体积材料进入 IndexedDB。按 **考试类型 / 年份 / 场次 / 套别 / 模块 / 篇目**建稳定索引；重复文件除文件指纹外核对卷别和内容，缺题干在入库前拒绝或标记待修复，绝不渲染成“1. 16”。
4. 定义 `keeplrn-progress` **v2** 便携文件：包括所有学习记录、生词本、草稿/自定义题、树园、个人题库正文、`importedPapers` 及其来源和版本信息；明确**排除** `settings`、AI Key、缓存的公开 44 MB 资源。导入先展示来源设备/时间/记录数/将覆盖的范围，确认后一次性替换便携字段与个人题库；先生成可回滚的本机快照，失败时保留原数据。旧版 v1 单独迁移并提示其可能缺少电脑磁盘上的个人题库，不得当成完整包。
5. 页面启动必须先完成本地数据迁移/读取，再合并只读题库并渲染。写入失败、存储不足、离线包未就绪必须在界面可见，不能只写 `console.warn`。保持桌面 `serve.js` 路径可用，同时让 PWA 路径完全不依赖它。

## 4. 分阶段安排与验收门槛

### 阶段 A：冻结基线和发布构建

- 记录 `git status` 和当前功能清单，不覆盖未提交内容；盘点所有静态引用和用户数据入口。
- 产出 `dist-pwa/` 和文件清单（文件数、总字节、最大单文件）；把约 44 MB 作为**目标估计**，以实际发布包测量为准。Cloudflare Pages 当前单文件上限为 25 MiB，构建时逐项检查。
- **过关条件：**发布目录独立通过 HTTPS/本机静态服务运行；无个人题目、密钥、原始 PDF；不存在缺失资源。

### 阶段 B：离线资源与本机存储

- 完成离线预下载、进度/错误提示、版本更新及失败回退；把个人题库从 `localStorage` 迁到 IndexedDB，并补存储空间/持久存储检查。
- 完成 v2 备份的双向覆盖式导入；电脑端导出要包含磁盘中个人题目。`settings` 与 AI Key 必须保持接收设备原值。
- **过关条件：**全新平板首次联网准备完资源后，开启飞行模式，冷启动并使用所有必需词书和五大练习模块；导入多套 PDF 后关闭/重启 PWA，题库仍在；平板→电脑→平板均能通过文件备份准确覆盖，重复导入有提示。

### 阶段 C：8.8 英寸 Android 真机功能与布局

- 从 Chrome 安装到桌面，检查全屏独立窗口、76px Rail、竖屏单词页指定顺序；横屏可恢复两列，≥1100px 桌面界面不回归。
- 检查九个页面和树园/统计；所有重要触摸目标至少 44 CSS px，正文/辅助文字、按钮不卡边，不发生页面级横向滚动。需要横向展示的表格或题目控件单独处理，并实测触控笔、深色模式与系统字体缩放。
- 真机试听男/女声、单词、听力，验证无网本地音色、联网可选音色及安装指引；验证 PDF/DOCX/TXT 文件选择、相机、手写、备份导出/导入、PDF 导出和 AI 请求。Android Web Speech 若不提供云端音色，应以用户自选且允许浏览器跨域调用的在线 TTS 提供方实现**显式启用**的云端选项；未配置或请求失败时退回本地音色并说明原因。不能凭设置开关声称云端音色可用，也不得把在线语音文本发送到未经用户选择的服务。
- **过关条件：**逐项记录平板型号、Android/Chrome 版本、竖横屏截图、音色清单和实际发声结果；关键路径无裁切或静音。

### 阶段 D：Cloudflare Pages 预览与 PWA 内测

- 把经过隐私扫描的 `dist-pwa/` 先部署到**预览环境**；同一固定 HTTPS origin 跑安装、离线、更新和数据恢复。正式域名/路径确定后再长期使用；更换 origin 会换一份浏览器本机存储，须先导出 v2 备份再导入。
- 实测用户 AI 服务从 Pages origin 能否直接请求（含 CORS/预检）；只使用用户明确配置的 AI 服务。无法跨域的服务需记录为限制或另选符合要求的提供方，不能私设云端转发器。
- **过关条件：**Pages 上的全新 Android 平板完成首次缓存后，飞行模式冷启动通过；升级发布版本后数据仍在、缓存没有混用新旧资源；浏览器站点数据删除后的恢复可由备份完成。

### 阶段 E：可选 TWA APK

- **仅在阶段 D 通过后做。**用 Bubblewrap 读取最终 HTTPS `manifest.webmanifest` 生成 Android 工程，使用稳定包名和签名密钥；在站点 `.well-known/assetlinks.json` 配置包名及**实际签名证书** SHA-256 指纹。先用 ADB 安装内测 APK。数字资产关联未通过时可能回落带浏览器栏的 Custom Tab。
- 在同一平板验证 TWA 与 PWA 的本机数据/离线包能否直接复用；不能复用时走 v2 备份迁移。首次离线启动可能没有 Service Worker，应提供“首次需联网完成离线包准备”的明确引导。
- **过关条件：**APK 图标启动无浏览器栏、断网重启可学习、文件导入/导出和语音/AI 行为与阶段 D 一致；保留签名密钥及升级路径。不把 TWA 描述为完全摆脱浏览器或首次安装即全离线的原生应用。

## 5. 必测矩阵（每项留证据）

| 场景 | 必须看到的结果 |
| --- | --- |
| 初次安装，联网 → 飞行模式 → 强制结束后重开 | 首页、单词、听力、阅读、写作、翻译及必要题库均可打开；AI/在线音色明确提示需要网络 |

| 本地男/女声、单词发音、停止/重播 | 无网能出声，试听/语速/音色选择生效；时间与原桌面逻辑一致 |
| 平板→电脑→平板 v2 备份 | 学习记录和个人题库与来源快照一致；接收设备原设置/AI Key 不变；导入前可预览，失败可回滚 |
