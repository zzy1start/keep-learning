# 33 · 拼写完成页统计缺失修复（2026-10-21）

> 用户真机反馈：完成一轮拼写练习后，完成页的「本轮征服 / 本轮正确率」等没有数据，正确率显示 `—%`；
> 另发现「本词书已学 126 · 已掌握 160」这种已学小于已掌握的矛盾显示。
> 版本：`1.1.19-test`，versionCode 41（40 修 mastered 口径，41 补首页「已掌握」镜像）。

## 1. 根因

### 1.1 拼写/随机练习没有"本轮报告"
- 背单词页有两种流程：
  · 引擎轮（智能/新词/复习）：`_begin` → `VocabEngine.startRound()`，`this.vocabRound` 有值；
  · 轮外练习（拼写/随机）：`_begin` 显式 `this.vocabRound = null`，判分走 `VocabEngine.gradeFree()`。
- 完成页却写死 `rep = (E && this.vocabRound) ? E.report(...) : null`，轮外练习永远拿不到报告：
  「本轮征服」退化成队列长度、「升级」恒 0、「本轮正确率」显示 `—%`（模板 `${rep ? ... : "—"}%`）。
- 同时 `_logSession()` 也拿 null，树园/统计只能拿到 `_goodCount`（拼写路径根本没维护它）。

### 1.2 拼写开始时没有载入引擎存档
- `_begin('spell'/'random')` 不调用 `_ensureEngine()`，第一次判分会直接 `VocabEngine.load()`（无 store）。
  而 `load()` 没有 store 时会缓存一个空状态；之后 `_ensureEngine()` 再 `load(Store)` 也拿不回真实进度，
  完成页会显示「已学 0」，甚至把本轮判分写进空状态。
- 真机复现：安装新包后直接走拼写 → `VocabEngine.load().words` 为空；改成 `_begin` 先 `_ensureEngine()` 后恢复正常（本机 3993 条词状态可读）。

### 1.3 已学/已掌握口径矛盾
- `stats()` 原为 `learned = attempts>0`、`mastered = level>=4`；定级会把整本词书的词批量写成 L1–L3/L4
  （不是用户学过），于是出现「已学 126 < 已掌握 160」。
- 现改为：**已学 = 作答过**；**已掌握 = 到 L4 且作答过**。定级批量写入不再冒充学习记录。

## 2. 改动

### 2.1 `js/views/vocab.js`
- 新增轮外练习统计：`_resetFreeStats / _noteFreeResult / _freeReport / _roundReport`。
  · 每个词位只按"第一次作答"计入本轮征服与正确率（拼写可重试，重试后答对不改变首答正确率）；
  · `gradeFree()` 返回的 `feedback.upgraded` 收集为「本轮升级」；首答错误进「下轮优先」。
- `_answer()`（随机练习 free 分支）与 `_spellCheck()` 记录判分结果。
- `_begin()`：开始任何模式都先 `_ensureEngine()` 载入真实存档，再 `_resetFreeStats()`。
- `_finish()` 与 `_logSession()` 统一用 `_roundReport()`：引擎轮用引擎报告，轮外练习用本地报告；
  完成页「本轮征服 / 升级 / 正确率 / 本轮升级 / 下轮优先」都有真实数据。

### 2.2 `js/vocab-engine.js`
- `stats()`：`learned` 仅统计 attempts>0；`mastered` 要求 level>=4 且 attempts>0。
- `mirrorToSrs()` 补写 `interval`（L4→30 天、L3→7 天）：首页 `Store.bookProgress` 用 `interval>=21` 判已掌握，旧镜像没这个字段 → 首页「掌握 0」。

### 2.3 测试
- 新增 `tools/check-vocab-round-stats.cjs`（6 项，check-all 自动纳入）：
  轮外报告 total/正确率/升级/难词、同词重试不重复计数、完成页不再出现 `—%`、
  已学/已掌握口径、拼写开始前载入真实引擎存档、save 后 load 不丢状态。
